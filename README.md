# 화면의 문법

웹 디자인·모션 그래픽, 그리고 영상 촬영·편집의 핵심 원리를 **움직이는 다이어그램으로 한 단계씩** 배우는 무료 인터랙티브 강의입니다.

- **웹 디자인 · 모션** (41개 레슨): 보는 법 · 글자 · 색 · 움직임의 문법 · 모션 그래픽 도구 · 브라우저가 그리는 법 · 데이터 시각화 · GPU와 3D
- **영상 촬영 · 편집** (12개 레슨): 프레이밍 · 카메라와 빛 · 편집

빌드 없는 정적 사이트입니다(HTML · CSS · 바닐라 JS, 캔버스 2D). 로컬에서 보려면:

```sh
python3 -m http.server 4173
# http://localhost:4173
```
